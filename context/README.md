# Dark Chat — Контекст проекта

## Что это
Dark Chat — AI-ассистент с генерацией кода, изображений, видео и самообучающейся системой. Полностью бесплатный, работает через OpenRouter.ai (бесплатные модели) и Pollinations.ai.

## Где.deploy
- **Бэкенд:** https://dark-chat-api.onrender.com (Render Free, Python 3.12.11)
- **Фронтенд:** https://dark-chat-puce.vercel.app (Vercel Free)
- **Репозиторий:** https://github.com/DarkTheme404/dark-chat

## Текущая версия
- API: v3.2.0
- Фронтенд: cyberpunk UI с анимацией нейросети

## Стек
- **Бэкенд:** FastAPI, SQLite, httpx, asyncio
- **Фронтенд:** React + TypeScript + Vite
- **AI:** OpenRouter.ai (бесплатные модели), Pollinations.ai (изображения)
- **Деплой:** Render (бот) + Vercel (фронт)
