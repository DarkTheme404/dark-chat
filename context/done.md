# Что сделано (хронология)

## Фаза 1: Основа
- Создан FastAPI бэкенд с эндпоинтами chat, code, image, video
- Создан React фронтенд с табами
- Подключён OpenRouter.ai (бесплатные модели)
- Подключён Pollinations.ai (изображения)

## Фаза 2: Self-learning
- Добавлена система feedback (1-5 звёзд)
- Автосбор training pairs из ответов AI
- Экспорт в форматах Alpaca/ShareGPT
- Таблица model_scores для скоринга моделей

## Фаза 3: Сессии
- CRUD сессий (список, создание, чтение, удаление)
- Автоназвание сессий (prefix-stripping)
- История сообщений из БД (последние 10)

## Фаза 4: Файлы
- Загрузка файлов (изображения, аудио, видео, документы)
- AI vision анализ изображений
- Groq Whisper STT для аудио
- ffmpeg извлечение кадров из видео

## Фаза 5: Трейдинг
- TradingView виджет
- Yahoo Finance прокси (обход CORS)
- AI анализ графика (тренд, уровни, рекомендации)
- Подбор инструментов по цели трейдера

## Фаза 6: Озвучка
- Web Speech API TTS с разбивкой на предложения
- STT через микрофон
- Настройки скорости, тона, громкости

## Фаза 7: Deep Thinking
- Тумблер «Глубокое мышление» / «Быстрый режим»
- Быстрые модели: nemotron-nano-9b, gemma-4-31b
- Умные модели: nemotron-550b, nemotron-120b
- Параллельный вызов 2 моделей

## Фаза 8: Cyberpunk UI
- Canvas анимация нейросети (40 узлов)
- Scanlines эффект
- Neon glow (cyan, magenta, purple)
- Thinking toggle с подписью

## Фаза 9: Стабильность
- Глобальный exception handler
- DB auto-recovery при повреждении
- try/except на всех DB-операциях
- Health check проверяет БД
- asyncio.ensure_future для параллельных вызовов
