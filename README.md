# Dark Chat

AI-powered чат с генерацией кода, изображений и видео. Самообучающаяся система.

## Возможности

### AI-функции
- **Чат** — Mistral 7B (Hugging Face API)
- **Код** — DeepSeek Coder 6.7B
- **Изображения** — Stable Diffusion XL
- **Видео** — CogVideoX 5B

### Система обучения
- **Автоматическое сохранение** всех запросов
- **Отзывы** с оценкой 1-5 звёзд
- **Категории отзывов**: точность, полезность, креативность, качество кода
- **Экспорт данных** для fine-tuning
- **Пары для обучения** из хороших ответов (4-5 звёзд)

### Админ-панель
- **Статистика**: запросы, отзывы, рейтинг
- **Просмотр отзывов** с контекстом
- **Управление обучением**: экспорт, применение

## Быстрый старт

### 1. Клонировать
```bash
git clone https://github.com/DarkTheme404/dark-chat.git
cd dark-chat
```

### 2. Запустить через Docker
```bash
docker-compose up
```

### 3. Или вручную

**Backend:**
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### 4. Открыть
- Frontend: http://localhost:3000
- API Docs: http://localhost:8000/docs

## API Endpoints

### AI
| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/chat/` | POST | Чат с AI |
| `/api/code/generate` | POST | Генерация кода |
| `/api/image/generate` | POST | Генерация изображений |
| `/api/video/generate` | POST | Генерация видео |

### Обучение
| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/feedback/submit` | POST | Отправить отзыв |
| `/api/feedback/stats` | GET | Статистика обучения |
| `/api/feedback/recent` | GET | Последние отзывы |
| `/api/feedback/training/export` | GET | Экспорт данных |
| `/api/feedback/training/apply` | POST | Применить обучение |

## Как работает обучение

1. **Пользователь** отправляет запрос
2. **Бот** отвечает и сохраняет в БД
3. **Пользователь** оценивает ответ (1-5 звёзд)
4. **Хорошие ответы** (4-5) автоматически становятся обучающими данными
5. **Данные экспортируются** для fine-tuning модели
6. **Модель дообучается** на пользовательских данных
